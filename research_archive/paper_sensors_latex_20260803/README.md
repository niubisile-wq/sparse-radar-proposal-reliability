# Sensors manuscript package

This directory is the submission-candidate package synchronized on
4 August 2026.

## Main files

- `paper_sensors_20260803.tex`: main LaTeX manuscript.
- `paper_sensors_20260803.pdf`: compiled 23-page manuscript.
- `references.tex`: bibliography entries.
- `Definitions/`: MDPI LaTeX class and supporting files.
- `figures/`: final figures, source tables, and plotting scripts.

The editable PowerPoint source for the overview architecture is
`figures/fig1_framework_overview.pptx`.

## Figure reproducibility

The CSV files and Python scripts for Figures 3--5 are stored alongside the
rendered PDF/PNG/SVG outputs. In particular,
`fig5_completed_voting_cells_source.csv` records the completed voting cells
used to replace the earlier unavailable entries in the sensitivity audit.

## Exclusions

LaTeX build intermediates, review contact sheets, downloaded literature used
for writing comparison, original datasets, model checkpoints, and private
infrastructure files are intentionally excluded from this clean manuscript
package.
