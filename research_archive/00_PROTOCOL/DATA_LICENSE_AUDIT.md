# Data License Audit

Date: 2026-07-28

## Scope

This audit covers the data sources used by the current EAAI extension round.

## Current conclusion

- No new public dataset is being created here.
- No external proprietary data source is being introduced.
- The current work uses existing radar datasets and derived artifacts already
  present in the workspace.

## Operational rules

1. Do not claim any newly created dataset is public unless its license and
   derivation path are explicitly documented.
2. Do not mix raw public data, synthetic outputs, and annotated cases without a
   traceable derivation note.
3. If a later step produces manually annotated difficult cases, those cases must
   be documented separately as derived / internal-use evidence.

## Status

This audit is a guardrail for the current protocol freeze. It does not by
itself grant permission for any new dataset release.
