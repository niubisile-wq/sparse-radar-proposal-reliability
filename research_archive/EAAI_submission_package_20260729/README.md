# EAAI LaTeX manuscript

Two synchronized manuscript layouts are retained:

- `paper.tex` / `paper.pdf`: anonymous single-column EAAI submission version.
- `paper_double_column.tex` / `paper_double_column.pdf`: retained two-column
  Elsevier `5p` reading version.

Both versions use the same figures and `references.tex`. The single-column
version is the file intended for EAAI submission because the journal's current
desk-review requirements specify single-column formatting.

Additional submission files:

- `highlights.txt`: separate four-item highlights file.
- `title_page_template.tex`: author title-page template that still requires
  author-supplied identities, affiliations, CRediT roles, funding, and
  acknowledgements.
- `SUBMISSION_READINESS.md`: final readiness checklist and known scientific
  limitations.

The manuscript is grounded in the frozen experiment package
`paper_freeze_20260729_0359/`.
